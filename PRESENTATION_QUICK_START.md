# Interview presentation

## With internet

Open https://clubpulse-web-vkeerthi.onrender.com/#try a few minutes before presenting. Complete one practice invitation exchange to verify both services are awake. A Free service can sleep again after inactivity; this is not a guarantee of uninterrupted hosting.

Use the automatically prepared invitation, submit a rating and comment, switch to Practice organiser, add four labelled examples, then close and seal the practice report. Practice-only sealing skips the wait; real reports retain the minimum and cooldown.

The online administrator uses the account configured in Render. `local-preview-only` is not its password. Real participant invitations come from Administrator > Events > Invitations, for the selected open event.

## If internet or Render fails

1. Open the ClubPulse-Demo folder in the offline package.
2. Double-click Start-ClubPulse-Demo.cmd and keep its window open.
3. The browser opens http://localhost:3040/#try when the server is ready.
4. Demonstrate the same participant, organiser and report workflow.
5. If needed, local administrator sign-in is `admin@clubpulse.local` with password `local-preview-only`.

The packaged copy includes Node, dependencies and the built interface. No installation, internet, Render or Atlas connection is required. Ports 3040 and 3041 must be available. It listens only on this laptop. Closing its command window ends the local services; data is temporary. It uses two local listeners in one process, not independent infrastructure. Clearly describe this as the local demonstration, not the hosted database or real participant feedback.

Do not upgrade hosting, add payment information or use a monitoring service to keep Free instances awake for this demo. This backup adds no recurring service or payment.
